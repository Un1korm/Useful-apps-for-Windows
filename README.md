## AlterSend (Обмен файлами):
![](logo_img/altersend-img.jpg)

Скачать приложение:
  - [Официальный сайт](https://altersend.com/)

Бесплатный open-source сервис для прямого обмена файлами между устройствами через интернет или локальную сеть. В отличие от LocalSend, работает не только в одной Wi-Fi-сети: устройства соединяются напрямую (P2P), а при невозможности прямого соединения используется зашифрованный релейный сервер, который не видит содержимое файлов. Шифрование end-to-end, без аккаунта и облачного хранения, без ограничений по размеру (от 1 КБ до 200 ГБ), с поддержкой папок и возобновляемой передачей. Получателю не нужно устанавливать приложение — достаточно открыть ссылку в браузере. Доступен на Windows, macOS, Linux, iOS, Android и в вебе.

## TG WS Proxy (Обход блокировки TG):
![](logo_img/tg-ws-proxy-img.png)

Скачать приложение:
  - [GitHub](https://github.com/Flowseal/tg-ws-proxy)

Локальный MTProto-прокси сервер для ускорения работы Telegram Desktop, который перенаправляет трафик через WebSocket-соединения. Приложение поднимает прокси на `127.0.0.1:1443`, перехватывает подключения к IP-адресам Telegram и устанавливает WebSocket-соединение (TLS) к соответствующим DC через домены Telegram. Данные передаются в зашифрованном виде, для работы не нужны сторонние серверы. Работает в системном трее — достаточно один раз настроить Telegram и забыть. Доступно для Windows 7/10/11, macOS и Linux.

Позволяет получить доступ к фотографиям, контактам, календарям, заметкам, закладкам Safari и паролям прямо на ПК. Поддерживает общий доступ к файлам через проводник и автоматическую загрузку фото из облака. Приложение доступно на платформе Windows.
